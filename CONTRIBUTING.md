# Contributing

Contributions are welcome. For changes that affect deletion, startup behavior, services, registry, pagefile, or system security:

1. Explain the problem and expected benefit.
2. Document exactly which paths/settings are affected.
3. Prefer report-only diagnostics before automated changes.
4. Require explicit confirmation for destructive or hard-to-reverse actions.
5. Never add telemetry, network calls, credential collection, or silent elevation.
6. Test on a disposable Windows 11 VM and include the test environment and results.
7. Keep user-facing documentation available in English and Persian when practical.
