# بهینه‌ساز امن ویندوز | MohZarg

مجموعه‌ای آزمایشی برای تشخیص و پیشنهاد بهینه‌سازی در ویندوز ۷، ۸٫۱، ۱۰ و ۱۱ با لانچر جداگانه و سه پروفایل سخت‌افزاری. این ابزار سرویس‌ها را غیرفعال نمی‌کند، رجیستری را تغییر نمی‌دهد و برای پاک‌سازی فایل‌های موقت تأیید می‌گیرد.

## نسخه‌ها
- Windows 7 SP1: scripts/Windows7/Start-Windows7.ps1 — نیازمند PowerShell 5.1 و پیش‌نیازهای آن؛ خارج از پشتیبانی عمومی.
- Windows 8.1: scripts/Windows81/Start-Windows81.ps1 — نیازمند PowerShell 5.1؛ خارج از پشتیبانی عمومی.
- Windows 10: scripts/Windows10/Start-Windows10.ps1 — نیازمند PowerShell 5.1؛ نسخه معمولی خارج از پشتیبانی عمومی.
- Windows 11: scripts/Windows11/Start-Windows11.ps1 — نیازمند PowerShell 5.1.
هسته مشترک: scripts/common/Invoke-SafeOptimizer.ps1. هر لانچر نام سیستم‌عامل را بررسی می‌کند.

## پروفایل‌ها
- LowEnd: تمرکز بر فضای خالی دیسک، تشخیص فشار RAM/دیسک، کاهش برنامه‌های هم‌زمان و پرهیز از ابزارهای RAM Booster.
- Balanced: حفظ تنظیمات امن پیش‌فرض، بررسی Startup و تغییر یک مورد در هر مرحله.
- Performance: تشخیص گلوگاه CPU، دیسک و حافظه پیش از انتخاب راهکار.
پروفایل‌ها به‌صورت خودکار سرویس‌ها یا برنامه‌های Startup را خاموش نمی‌کنند؛ این محدودیت برای جلوگیری از خرابی سیستم عمدی است.

## اجرا
مخزن را دانلود و استخراج کنید. سپس در PowerShell، لانچر متناسب با ویندوز را اجرا کنید. نمونه ویندوز ۱۱:
powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File .\scripts\Windows11\Start-Windows11.ps1

در منو ۱ برای LowEnd، ۲ برای Balanced و ۳ برای Performance انتخاب کنید. فقط در صورت موافقت با پاک‌سازی فایل‌های TEMP قدیمی، y وارد کنید؛ Enter یعنی ردکردن. گزارش روی Desktop ذخیره می‌شود.

## مرزهای ایمنی
- سرویس‌ها، Scheduled Tasks، Startup، رجیستری، Pagefile، تنظیمات امنیتی و سیاست Windows Update خودکار تغییر نمی‌کنند.
- پوشه‌های شخصی، Downloads، Documents، Desktop، پروفایل مرورگر و کش Windows Update پاک نمی‌شوند.
- تنها پاک‌سازی اختیاری، فایل‌های بیش از ۷ روز عمر در TEMP کاربر جاری است؛ ابتدا فهرست و سپس تأیید گرفته می‌شود.
- ابزار عملیات تعمیر دیسک انجام نمی‌دهد و افزایش سرعت را تضمین نمی‌کند.

برای مشاهده فعالیت لحظه‌ای دیسک از Task Manager > Processes > Disk استفاده کنید. Pagefile مدیریت‌شده توسط ویندوز را غیرفعال نکنید. در صورت هشدار سلامت HDD، پیش از آزمایش‌های بیشتر از فایل‌های مهم نسخه پشتیبان تهیه کنید.

ویندوز ۷، ۸٫۱ و نسخه معمولی ویندوز ۱۰ خارج از پشتیبانی عمومی هستند؛ بهینه‌سازی عملکرد، پشتیبانی امنیتی را برنمی‌گرداند. تست ایستای GitHub جای آزمایش واقعی روی هر نسخه ویندوز را نمی‌گیرد.
