# بهینه‌ساز امن ویندوز ۱۱

ابزار PowerShell محافظه‌کارانه برای بررسی وضعیت ویندوز و پیشنهاد پاک‌سازی محدود فایل‌های موقت قدیمی.

> **وضعیت پروژه:** آزمایشی؛ بازبینی جامعه توسعه‌دهندگان موردنیاز است. بررسی ایستای کد، ایمنی اجرا روی تمام سیستم‌ها را تضمین نمی‌کند. پیش از اجرا، کد را بخوانید.

## قابلیت‌ها

- نمایش نسخه ویندوز، پردازنده، رم نصب‌شده و فضای آزاد درایوهای `C:` و `M:` در صورت وجود.
- نمایش پردازش‌هایی که بیشترین حافظه RAM را مصرف می‌کنند و پردازش‌ها بر اساس زمان تجمعی CPU.
- گزارش برنامه‌های Startup بدون غیرفعال‌کردن آن‌ها.
- تلاش برای نمایش نقاط System Restore موجود؛ نقطه بازیابی جدید ایجاد نمی‌کند.
- پیشنهاد پاک‌سازی اختیاری فایل‌های بیش از ۷ روز عمر در پوشه TEMP کاربر جاری؛ ابتدا فهرست می‌کند و سپس تأیید می‌گیرد.
- ذخیره گزارش روی Desktop.

## عمداً چه کارهایی انجام نمی‌دهد؟

- سرویس‌ها یا وظایف زمان‌بندی‌شده ویندوز را غیرفعال نمی‌کند.
- رجیستری را تغییر نمی‌دهد.
- فایل صفحه‌بندی (Pagefile) یا تنظیمات مدیریت حافظه را تغییر نمی‌دهد.
- پوشه‌های Downloads، Documents، Desktop، پروفایل مرورگر، سطل بازیافت یا کش Windows Update را هدف نمی‌گیرد.
- دستورهای تعمیر/حذف مخرب دیسک مانند `chkdsk /f` و `chkdsk /r` اجرا نمی‌کند.
- افزایش سرعت را تضمین نمی‌کند؛ هدف نخست، تشخیص مشکل است.

## نیازمندی‌ها

- Windows 11
- Windows PowerShell 5.1 (به‌صورت پیش‌فرض در ویندوز ۱۱ موجود است)
- برای گزارش‌های پایه معمولاً دسترسی کاربر عادی کافی است؛ بعضی اطلاعات ممکن است بدون دسترسی بالاتر در دسترس نباشند.

## اجرای سریع

1. فایل ZIP مخزن GitHub را دانلود یا مخزن را Clone کنید.
2. آن را در یک پوشه معمولی استخراج کنید.
3. روی `Run_Optimizer.bat` دوبار کلیک کنید.
4. متن هر پرسش را بخوانید. برای `[y/N]` فقط در صورت موافقت `y` بنویسید؛ Enter یعنی ردکردن.
5. گزارش `Windows11_Optimizer_*.log` را روی Desktop بررسی کنید.

اجرای مستقیم از PowerShell:

```powershell
powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File .\scripts\Windows11_Optimizer.ps1
```

اسکریپت‌هایی را که بررسی نکرده‌اید اجرا نکنید. برای گزارش‌های پایه، اجرای Administrator لازم نیست.

## نکات مهم برای HDD و رم ۸ گیگابایت

- فایل صفحه‌بندی مدیریت‌شده توسط ویندوز را فعال نگه دارید، مگر دلیل فنی مشخص و آزمایش‌شده‌ای داشته باشید.
- برای شناسایی مصرف زنده Disk، Task Manager → Processes را باز و ستون Disk را مرتب کنید. فهرست این اسکریپت اندازه‌گیری زنده I/O دیسک برای هر پردازش نیست.
- اگر HDD هشدار سلامت دارد، صدای کلیک غیرعادی می‌دهد یا گاهی ناپدید می‌شود، پیش از تلاش برای تعمیر، از فایل‌های مهم نسخه پشتیبان تهیه کنید.
- برای سیستم قدیمی دارای HDD، ارتقا به SSD SATA معمولاً بیشترین بهبود سخت‌افزاری را ایجاد می‌کند.

## مدل ایمنی

تنها عملیات حذف، پاک‌سازی اختیاری فایل‌های قدیمی داخل TEMP کاربر جاری است. موارد پیشنهادی ابتدا فهرست می‌شوند و حذف فقط با تأیید کاربر انجام می‌شود. فایل‌های قفل‌شده یا غیرقابل‌دسترسی رد می‌شوند. این روش خطر را کاهش می‌دهد، اما ایمنی همه فایل‌های موقت را در تمام سیستم‌ها تضمین نمی‌کند.

وضعیت Restore Point فقط گزارش می‌شود. نقطه بازیابی جایگزین نسخه پشتیبان نیست و این ابزار از فایل‌های شخصی بکاپ نمی‌گیرد.

## تست

Workflow گیت‌هاب بررسی‌های ساختاری و در صورت دسترس بودن PSScriptAnalyzer را اجرا می‌کند. تحلیل ایستا معادل اجرای واقعی روی ویندوز ۱۱ نیست. پیش از اتکا، در ماشین مجازی آزمایشی یا سیستم غیرحیاتی آزمایش کنید و گزارش را بررسی کنید.
